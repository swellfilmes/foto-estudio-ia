# Miniaturas de exemplo dos cards

Os cards de tipo de foto procuram imagens aqui. Enquanto o arquivo não existe,
o card mostra um ícone de placeholder. Proporção ~4:3, ~480px de largura, `.jpg`.

## Produto (funil Riverflow: identificar → inspecionar → entender → desejar)
- `fundo-branco.jpg`  → produto em fundo branco de marketplace
- `detalhe.jpg`       → macro na textura/rótulo
- `na-mao.jpg`        → mão segurando o produto (escala)
- `flat-lay.jpg`      → produto visto de cima com props
- `lifestyle.jpg`     → produto em cena real do cotidiano
- `hero.jpg`          → campanha premium com impacto
- `cg.jpg`            → render 3D premium

## Com modelo
- `influencia.jpg`         → UGC / selfie de cliente
- `estudio-modelo.jpg`     → modelo em estúdio com o produto
- `comercial-modelo.jpg`   → campanha com modelo
- `mostruario-modelo.jpg`  → modelo demonstrando/usando o produto

Assim que os arquivos estiverem aqui, os cards trocam o ícone pela foto sozinhos.
